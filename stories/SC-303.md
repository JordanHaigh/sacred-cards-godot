**Priority:** P0  
**Status:** TODO

## User Story

As a gameplay system, I want player and AI decisions represented through the same validated actions so both obey identical rules.

## Scope

The implementation agent MUST NOT begin another story until this story has either:

- been verified and committed as `DONE`, or

## Tasks

- Create action abstraction with validation, execution, and failure reasons.
- Support initial actions needed by the current duel model such as draw, summon/set, attack, position change, spell/trap actions, and end turn where applicable.

## Acceptance Criteria

- [ ] Illegal actions fail with explicit reasons.
- [ ] UI and AI can eventually call the same action interface.
- [ ] Actions modify only authoritative duel state.
